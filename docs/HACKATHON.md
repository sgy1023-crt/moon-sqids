# 2026 年 11 月黑客松事实记录

本页记录工程事实与公开规则，供参赛者核对。正式申报书须由参赛者本人以一页以内 Markdown 撰写。报名表明示不得使用 AI 编写申报书。

## 项目事实

| 项 | 当前事实 |
| --- | --- |
| 名称与赛道 | MoonSqids。拟申报「新项目申报-不参与季度评选」，方向为工具库。 |
| 独立性 | 在本轮新建独立 Git 仓库，从零编写 MoonBit 实现。算法来自 Sqids，官方 blocklist 完整保留。公开查重未发现成熟的直接 MoonBit 兼容实现。 |
| 工程进度 | 0.1.0 本地已实现编码、解码、自定义 ASCII 字符表、最小长度、默认与自定义 blocklist、精确整数上界和类型化错误。 |
| 使用场景 | 单个记录 `12345 → A6da → 12345`。租户、分区、记录 `[7, 3, 12345] → RMeyNPxf` 可放入 URL 参数。与官方 JavaScript 包双向互通，覆盖最大安全整数。 |
| 验证 | Native 和 JS 各 19 项测试、1915 项官方 JS 差分、1 项独立 ZIP 消费测试通过。三例均已运行。 |
| 仓库与包 | 本地独立仓库 `moon-sqids`，分支 `main`。公开 GitHub URL 待确定。本地模块暂用 `sgy/moon-sqids@0.1.0`，Mooncakes 尚未发布。 |
| 许可 | MoonSqids、JavaScript 参考实现和默认 blocklist 均采用 MIT。具体上游来源见 NOTICE。 |

## 已核实规则

核对日期为 2026 年 11 月 10 日（北京时间）。依据 11 月官网部署对应的源码、该月报名表、章程和表单链接的诚信承诺书。

- 月度新项目允许有生态价值的成熟项目移植。官网允许用 AI 辅助代码、测试与项目文档，参赛者须能解释自己的提交。表单要求公开 GitHub 仓库及至少 10 个有效 commits。无意义拆分、空提交或重复提交不计。表单另要求本人撰写一页以内的 Markdown 申报书。
- 表单可提交三次并可重复修改。章程写每位参赛者原则上提交一个项目。多项目及每人一份月度支持的口径需以赛事方对参赛者的答复为准。若同时考虑已有项目维护赛道，核对两项能否并行及哪项可获得资助。
- 新项目初审通过后可获 150 元启动支持。按申报范围完成并验收通过后可获 350 元完成支持。章程要求公开可追溯的开发记录和实际发布到 Mooncakes。诚信承诺书规定，虚假或违规情况下，组织方可要求返还已发激励。
- 11 月官网将报名、验收等具体截止时间指向当月通知。公开资料未核实精确时间、普通诚实延期或未完成是否需退还启动支持，以及在初审前已经实现核心功能是否影响当月启动资格。申报应如实披露当前进度和提交时间。
